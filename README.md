# Music Player

Minimalist audio player built with a focus on performance and design
responsive. Includes song navigation, volume control, playback
shuffle and repeat modes, all in a clear and accessible interface.

## Functional requirements

* Playback controls: go back, pause and skip forward between songs
* Volume control: adjust the sound level
* Audio selection: choose songs from the navigation bar
* Random play: activate shuffle mode for random play
* Repeat modes: repeat the entire list or just the current song

## Non-functional requirements

* Performance: Fast app loading and smooth transitions
* Responsive design: adaptable to different sizes (mobile, tablet, desktop)
* Clear interface: intuitive and easy to identify controls
